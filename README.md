# 🔬 Comparative Study for Software Development in COCOMO I and COCOMO II

> A co-authored academic research paper exploring software development cost and effort estimation using COCOMO I and COCOMO II.

## 📌 About the Research

**“Comparative Study for Software Development in COCOMO I and COCOMO II”** focuses on the comparison of COCOMO I and COCOMO II models used for software project estimation.

The research explores how these models can be used to estimate factors such as software development effort, cost, and project schedules.

Compared with our earlier research experience, this paper gave us an opportunity to explore a more technical topic related to **software engineering and project estimation**.

## 🔍 Topics Covered

- Introduction to Software Project Estimation
- Software cost estimation
- Software effort estimation
- COCOMO model
- COCOMO I
- COCOMO II
- Comparison between COCOMO I and COCOMO II
- Software development estimation
- Factors affecting project estimation
- Applications of COCOMO models
- Advantages and limitations
